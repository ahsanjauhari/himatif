# HIMATIF UNTIDAR — Website Statis

## Struktur
- `index.html` — halaman utama
- `style.css` — seluruh styling dan responsive design
- `script.js` — menu mobile dan animasi ringan
- `assets/logo.png` — logo HIMATIF
- `assets/struktur.png` — gambar struktur organisasi
- `assets/dokumentasi-1.jpg` sampai `dokumentasi-6.jpg` — foto dokumentasi kegiatan

## Cara menggunakan
1. Buka folder website.
2. Masukkan logo HIMATIF dengan nama `logo.png` ke folder `assets`.
3. Masukkan gambar struktur organisasi dengan nama `struktur.png`.
4. Masukkan foto dokumentasi dengan nama `dokumentasi-1.jpg` hingga `dokumentasi-6.jpg`.
5. Buka `index.html` di browser.

Website tidak memakai backend, database, login, atau server-side processing.
Video profil menggunakan embed YouTube dari video yang diberikan.
