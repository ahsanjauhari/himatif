# HIMATIF UNTIDAR — Website Statis v2

Versi revisi berdasarkan logo HIMATIF dan contoh foto yang diberikan.

## Prinsip desain
- Tidak menggunakan CSS gradient.
- Tampilan lebih clean, editorial, dan aesthetic.
- Warna utama: navy, sapphire, biru cerah, putih.
- Hero menggunakan foto kegiatan sebagai visual utama.
- Logo ditampilkan sederhana tanpa elemen ACTIVE/INNOVATIVE.
- Statistik 2024/TI/kolaborasi dihapus dari hero.
